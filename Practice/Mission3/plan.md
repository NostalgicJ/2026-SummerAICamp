# 사이버 윷놀이 (Cyber Yut Nori) — PRD

## 1. 개요

1:1 턴제 전통 윷놀이를 웹에서 즐길 수 있는 게임. 단일 HTML 파일로 구현하여 Claude Artifact로 등록하고, 스터디 그룹 및 JK와 공유하는 것을 최종 목표로 한다.

## 2. 학습 목표

- AI 에이전트와 함께 게임을 단계적으로 설계·구현하는 경험
- 턴 기반 1:1 게임 로직 구현
- 윷놀이 말판의 좌표/경로 시스템(지름길 포함) 구현

## 3. 기술 스택

- **순수 HTML/CSS/JS 단일 파일** (`index.html`), 외부 라이브러리·빌드 과정 없음
- 상태관리: 순수 JS 객체 (게임 상태를 하나의 `state` 객체로 관리)
- 렌더링: SVG 또는 CSS Grid로 말판 표현, DOM 조작으로 갱신
- 이유: Claude Artifact는 외부 CDN/스크립트 로드가 막혀 있어(strict CSP), 자체 완결형 단일 파일이어야 바로 등록·공유 가능

## 4. 게임 규칙 (최종 구현 기준)

- 참가자 2명, 각자 말 2개, 턴제로 진행
- 윷 던지기 결과: 도(1) / 개(2) / 걸(3) / 윷(4) / 모(5)칸 이동. 결과 표시는 항상 도개걸윷모 순서이며, 확률 수치(%)는 화면에 노출하지 않는다
- **윷·모가 나오면 추가로 한 번 더 던짐.** 던진 결과가 여러 개 쌓이면(예: 모+도) 어떤 결과를 먼저 말에 적용할지 플레이어가 선택한 뒤 이동한다
- **상대 말이 있는 칸에 도착하면 그 말을 시작점으로 되돌리고(업혀 있었어도 각자 흩어짐), 잡은 즉시 한 번 더 던짐**
- **같은 편 말이 있는 칸에 도착하면 무조건 업는다 (선택 없음)** — 업은 말은 이후 하나의 묶음으로 항상 함께 이동하며, 잡히면 다시 개별로 흩어져 시작점으로 돌아간다
- 말판은 외곽 20칸 순환 경로 + **5번·10번 모서리**에서 중심을 경유하는 지름길 보유. 출발/도착점인 **0번 모서리는 지름길 없이 항상 외곽길로만 진행**한다 (전진만 가능)
- 지름길 한 변은 모서리-칸-칸-중심 순으로 **2칸씩** 구성되어, 모서리 간 총 6칸(모서리→중심 3칸 + 중심→반대 모서리 3칸)
- 지름길의 중앙(두 대각선이 교차하는 칸)에 정확히 멈추면, 다음 이동 시 **반대쪽 대각선으로 갈아탈지 그대로 진행할지 다시 선택**할 수 있다
- **말 2개가 모두 출발점을 지나 완주하면 승리**

## 5. 개발 단계 (Phase)

각 단계 완료 후 동작을 확인하고, 필요 시 새 대화창 또는 `/clear` 후 다음 단계로 진행한다.

### 1단계 — 정적 윷놀이판 렌더링
- 외곽 20칸 + 지름길 구조를 SVG/CSS로 시각화
- 말 초기 위치(출발점) 표시
- 보기 좋은 수준의 디자인(색상, 칸 강조 등)

### 2단계 — 턴 방식 + 윷 던지기
- 턴 전환 로직 (플레이어 A ↔ B)
- "윷 던지기" 버튼 및 결과 애니메이션
- 도개걸윷모 순서로 결과 이름 표시 (확률 수치는 표시하지 않음, 실제 확률 기반 랜덤 로직만 내부 반영)
- 윷·모 발생 시 추가 턴 로직 연결, 여러 결과가 쌓이면 적용 순서를 플레이어가 선택

### 3단계 — 말 이동
- 던진 결과만큼 선택한 말이 경로를 따라 이동
- 5번·10번 모서리 및 대각선 중앙에서의 지름길 분기 선택 처리 (0번 출발점은 분기 없음)
- 이동 가능한 말이 없을 경우(예: 모든 말 완주) 자동 턴 종료

### 4단계 — 업기 · 잡기
- 같은 편 말끼리 겹치면 자동으로 업기 (선택 없이 무조건 병합)
- 상대 말이 있는 칸 도착 시 잡기 처리(업힌 말도 개별로 흩어져 시작점 리셋 + 추가 턴)

### 5단계 — 승리 판정 및 UI/UX 마무리
- 말 2개 모두 완주 시 승리 판정 및 승리 화면(컨페티 연출 + 다시 시작)
- 반응형 레이아웃: 화면 폭 1000px 이상(PC)에서는 말판 카드와 조작판 카드를 좌우로, 높이를 동일하게 맞춰 배치. 그 미만(모바일/태블릿)에서는 세로로 쌓는다
- 다크모드 대응, 로그/안내문 등 텍스트 시인성 확보
