# 네이버 — 코딩테스트 경향 기록

## 조사일자
2026-07-28 (최초 기록)

## 1단계 결과: 기출 여부
프로그래머스에 네이버 관련 문제가 다수 존재하고("2024년 하반기 네이버 코딩테스트는 프로그래머스로 진행" 등) SQL 난이도 비교 언급도 있었으나, 특정 문제명 + 신뢰 가능한 링크로 "이 문제가 네이버 기출이다"라고 확정할 수 있는 자료는 이번 검색에서 찾지 못함. 확인된 정보는 대부분 지원자 후기 수준(시험 형식·시간·문항 수·난이도 체감)에 머무름 → **기출 불충분으로 판단, 2단계(자체 제작)로 진행**.

## 2단계: 경향 요약
- **시험 플랫폼**: 최근에는 프로그래머스와 Codility가 혼용됨. 2024년 하반기 신입 공채는 프로그래머스, 최근 경력 채용은 Codility(IDE·화면녹화 불가 환경)로 진행됐다는 후기 확인
- **문제 구성**: 신입 공채 기준 2시간에 알고리즘 3문제 + SQL 2문제 구성이 언급됨. 관계사(네이버 라인)는 3시간 6문제(문항당 약 30분) 구성이라는 후기도 있어 계열사별 편차가 있음
- **난이도**: "브론즈~골드 하위" 수준으로 언급되는 경우가 많고, 최근 신입 공채는 CS 객관식 약 20문항이 추가되는 등 알고리즘 외 영역도 함께 평가하는 경향
- **출제 철학**: "특정 알고리즘을 아는지"보다 "그 로직을 코드로 정확히 표현할 수 있는지"에 초점을 둔다는 후기가 여럿 확인됨 → 표준 알고리즘(그래프 탐색, 정렬, 위상정렬 등)을 알고 있어도 예외 처리·종료 조건 등 구현 디테일에서 실수하는지를 본다는 뉘앙스
- **유형**: 구현이 가장 자주 언급되고, 그 외 그래프/BFS/DFS, 문자열 처리 등이 함께 언급됨. 특정 자료구조 지식보다 모델링 정확도를 중시

## 2026-07-28 갱신: 파이프라인 방식 변경 (AI 자체 제작 → 검증된 문제풀 매칭)
이전에 AI가 자체 제작했던 "부스트캠프 학습 트랙 최소 완료 라운드" 문제는 폐기했습니다. 이제부터는 새 문제를 만들지 않고, 위 경향에 맞는 **실제 존재하는 검증된 문제**를 프로그래머스/SWEA/리트코드에서 찾아 매칭 추천합니다.

### 매칭 추천 문제
- **타겟 넘버** / 프로그래머스 / https://school.programmers.co.kr/learn/courses/30/lessons/43165 (DFS/재귀/완전탐색, 레벨 2)
- 매칭 근거: 회사 태그 없이 등록된 DFS/재귀 완전탐색 문제로, "정확한 구현"을 중시하고 그래프 탐색형 사고를 요구하는 네이버 경향(구현/그래프 탐색/브론즈~골드 난이도)과 잘 맞음
- `data/problems.json`에 `naver-target-number-01`로 반영 완료. `source: "경향문제"`

### 기존 문제 재분류 결과 (WebFetch로 재검증)
기존 "네이버" 라벨 5개 전부 특정 기업 기출 태그 없이 일반 "코딩테스트 연습" 유형 분류(DFS/BFS, 탐욕법, DP 등)만 존재함을 확인 — 전부 `source`를 `"기출"` → `"경향문제"`로 수정 (게임 맵 최단거리, 섬 연결하기, N으로 표현, 정수 삼각형, Course Schedule)
