# 쿠팡 — 코딩테스트 경향 기록

## 조사일자
2026-07-28 (최초 기록)

## 1단계 결과: 기출 여부
프로그래머스 "기업 기출문제" 코너나 SWEA, 쿠팡 공식 기술 블로그에서 특정 문제명·문제 링크로 확정할 수 있는 쿠팡 명의의 공개 기출문제는 이번 검색에서 찾지 못함. 검색되는 정보는 대부분 개인 합격/면접 후기(블로그, 블라인드, 잡플래닛)에 한정됨 → **기출 불충분으로 판단, 2단계(경향 수집) 및 3단계(자체 제작)로 진행**.

## 2단계: 경향 요약
- **온라인 코딩테스트**: 한 후기에서는 3문제, 150분 제한, "개인적으로는 평이한 수준"이라는 체감 난이도가 언급됨. 응시자는 1시간 미만으로 조기 종료했다고 서술.
- **라이브 코딩테스트(페어 프로그래밍)**: 면접관과 함께 화면을 공유하며 푸는 방식으로, 지문을 직접 읽게 하기보다 면접관이 입출력을 구두로 설명해주는 진행 방식이 언급됨. 세션당(약 1시간) 1문제가 기본이고, 빨리 풀면 추가 문제가 나오는 구조. 총 2~3개 기술 세션으로 구성된다는 후기 확인.
- **준비 플랫폼**: HackerRank에서 사전 연습했다는 후기와, 일부 팀은 해외 플랫폼인 Codility를 쓴다는 언급도 확인됨.
- **알고리즘 유형**: 기본 자료구조(배열, 스택, 큐, 트리, 그래프) + 다이나믹 프로그래밍, 그리디 알고리즘 준비를 권장하는 내용이 공통적으로 언급됨. 특정 고난도 유형(고급 그래프 이론, 특수 자료구조 등)을 강조하는 후기는 확인되지 않음.
- **면접 전반 분위기**: 화이트보드/손코딩을 요구하는 기술면접 단계도 있다는 언급이 있었으나, 이는 온라인/라이브 코딩테스트와는 별개의 심화 면접 단계로 보임.

## 2026-07-28 갱신: 파이프라인 방식 변경 (AI 자체 제작 → 검증된 문제풀 매칭)
이전에 AI가 자체 제작했던 "무인 택배함 LRU 재배치" 문제는 폐기했습니다. 이제부터는 새 문제를 만들지 않고, 위 경향에 맞는 **실제 존재하는 검증된 문제**를 프로그래머스/SWEA/리트코드에서 찾아 매칭 추천합니다.

### 매칭 추천 문제
- **구명보트** / 프로그래머스 / https://school.programmers.co.kr/learn/courses/30/lessons/42885 (그리디/정렬/투포인터, 레벨 2)
- 매칭 근거: 기본 자료구조(정렬/투포인터) + 그리디 유형이며 난이도가 평이해, "3문제/150분" 온라인 테스트에서 나올 법한 체감 난이도와 잘 맞음
- `data/problems.json`에 `coupang-lifeboat-01`로 반영 완료. `source: "경향문제"`

### 기존 문제 재분류 결과 (WebFetch로 재검증)
기존 "쿠팡" 라벨 4개 전부 특정 기업 기출 태그 없음을 확인 — 특히 "다리를 지나는 트럭"은 문제 내 출처가 "2016 ICPC Korea Online"으로 명시되어 있어 쿠팡과 무관함이 확인됨. 전부 `source`를 `"기출"` → `"경향문제"`로 수정 (다리를 지나는 트럭, 기능개발, 프로세스, Coin Change)
