# 현대오토에버 — 코딩테스트 경향 기록

## 조사일자
2026-07-28 (최초 기록)

## 1단계 결과: 기출 여부
프로그래머스 "기업 기출문제" 코너나 SWEA, 공식 기술 블로그 등 인정 가능한 출처에서 현대오토에버 명의로 공개된 구체적인 기출문제(문제명 + 신뢰 가능한 링크)를 찾지 못함. 검색된 정보는 대부분 지원자 후기 블로그, 커뮤니티 글, 준비 팁 게시물 수준이며, acmicpc.net(백준)의 "현대오토에버 준비" 문제집은 이 프로젝트 정책상 소스로 인정하지 않음 → **기출 불충분으로 판단, 2~4단계(경향 수집 + 자체 제작)로 진행**.

## 2단계: 경향 요약
- **시험 형식**: 자체 코딩 플랫폼 "소프티어(Softier, 현대차그룹 전용 플랫폼)" 또는 프로그래머스를 통해 진행되며, 최근 후기 기준 약 2~3시간 동안 3문제를 푸는 구성이 다수 확인됨
- **난이도**: 다른 IT 서비스 기업 대비 난이도가 낮은 편이라는 후기가 다수이며, 백준 기준 실버1~골드4 수준이라는 언급이 반복적으로 확인됨 (참고용 비교이며 백준 자체를 문제 소스로 쓰지는 않음)
- **알고리즘 유형**: 배열·문자열·정렬·스택·큐·그래프 탐색(BFS/DFS)·그리디·완전탐색이 안정적으로 나오는 유형으로 언급됨. 세그먼트 트리 같은 심화 자료구조·알고리즘보다는 조건이 복잡한 시뮬레이션과 완전탐색 구현력을 보는 경향이 강하다는 후기가 여러 출처에서 공통적으로 확인됨
- **채점 포인트**: 한 문제에 알고리즘 하나만 단순 적용하기보다 창의적 아이디어나 2개 이상의 개념을 조합해야 하는 경우가 있다는 후기도 있어, 순수 난이도는 낮아도 "정확한 구현"이 당락을 가른다는 인상

## 2026-07-28 갱신: 파이프라인 방식 변경 (AI 자체 제작 → 검증된 문제풀 매칭)
이전에 AI가 자체 제작했던 "정비소 리프트 배정 시뮬레이션" 문제는 폐기했습니다. 이제부터는 새 문제를 만들지 않고, 위 경향에 맞는 **실제 존재하는 검증된 문제**를 프로그래머스/SWEA/리트코드에서 찾아 매칭 추천합니다.

### 매칭 추천 문제
- **소수 찾기** / 프로그래머스 / https://school.programmers.co.kr/learn/courses/30/lessons/42839 (완전탐색/문자열/수학, 레벨 2)
- 매칭 근거: 세그먼트 트리 같은 심화 알고리즘 없이 순열 생성과 소수 판별만으로 풀리는 순수 완전탐색·구현 문제로, 현대오토에버가 선호하는 "조건이 복잡한 완전탐색·구현력" 유형과 난이도에 부합
- `data/problems.json`에 `hyundai-prime-find-01`로 반영 완료. `source: "경향문제"`

### 기존 문제 재분류 결과 (WebFetch로 재검증)
- 다트 게임: 페이지 상단에 "2018 KAKAO BLIND RECRUITMENT" 태그가 확인됨 — 이는 현대가 아니라 카카오의 실제 기출임. `source`를 `"기출"` → `"경향문제"`로 수정
