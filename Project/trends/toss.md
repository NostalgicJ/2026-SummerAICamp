## 1단계 결과: 기출 여부
**기출 확인됨(2026-07-30 재검증 완료).** toss.im은 브라우저 정책상 직접 접속이 차단되어 있고 WebFetch도 클라이언트 렌더링 영역까지는 가져오지 못해 최초 조사 때는 미검증으로 남겨뒀으나, WebSearch로 다른 경로(velog 후기 등)를 통해 실제 예시(입력 "111999333" → 출력 999, 111/333/999 중 최댓값 반환)까지 구체적으로 확인되어 기출로 확정한다.

- **문제명**: 멋쟁이 숫자
- **출처**: 토스 공식 커리어 페이지(기업 공식 기출문제 공개 아티클)
- **링크**: https://toss.im/career/article/next-developer-2023-sample-questions
- **유형·난이도**: 2022년 토스 NEXT 개발자 챌린지 서버 직군 코딩테스트 문제 중 난이도가 가장 낮은 문제로 공개됨. 문자열/반복문 기반 기초 구현 문제 — 길이 3짜리 부분 문자열 중 세 자리 숫자가 모두 같은 "쌍둥이 숫자" 형태를 찾아 가장 큰 값을 반환(없으면 -1, 000이면 0 처리)하는 방식.
