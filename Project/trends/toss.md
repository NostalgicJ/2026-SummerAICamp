## 1단계 결과: 기출 여부
**페이지 존재는 확인, 구체적 문제명은 미검증.** 토스가 "[토스 NEXT] 2022년 코딩테스트 기출문제를 공개해요"라는 제목의 공식 커리어 아티클을 실제로 게시했다는 것은 WebFetch로 확인했다. 다만 toss.im은 브라우저 정책상 직접 접속이 차단되어 있고, WebFetch도 이 페이지의 실제 문제 본문(클라이언트 렌더링 영역)까지는 가져오지 못해 아래 문제명·설명은 **사람이 직접 링크를 열어 재확인하기 전까지는 미검증 상태**로 취급해야 한다.

- **(미검증) 문제명**: 멋쟁이 숫자
- **출처**: 토스 공식 커리어 페이지(기업 공식 기출문제 공개 아티클)
- **링크**: https://toss.im/career/article/next-developer-2023-sample-questions (페이지 존재 자체는 확인됨)
- **(미검증) 유형·난이도**: 2022년 토스 NEXT 개발자 챌린지 서버 직군 코딩테스트 문제 중 난이도가 가장 낮은 문제로 공개됨. 문자열/반복문 기반 기초 구현 문제 — 길이 3짜리 부분 문자열 중 세 자리 숫자가 모두 같은 "쌍둥이 숫자" 형태를 찾아 가장 큰 값을 반환(없으면 -1, 000이면 0 처리)하는 방식.
- **후속 조치 필요**: 사람이 위 링크를 직접 열어 문제명·설명이 실제로 일치하는지 확인 필요
