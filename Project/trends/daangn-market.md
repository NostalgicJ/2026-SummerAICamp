# 당근마켓 — 코딩테스트 경향 기록

## 조사일자
2026-07-28 (최초 기록)

## 1단계 결과: 기출 여부
프로그래머스에 당근마켓 명의의 채용 공개 코테가 존재한다는 정황은 있으나, 특정 문제명·문제 링크로 확정할 수 있는 공식 "기출문제" 페이지는 이번 검색에서 찾지 못함. 후기 위주의 간접 정보만 확인됨 → **기출 불충분으로 판단, 2단계(자체 제작)로 진행**.

## 2단계: 경향 요약
- **문제 구성**: 코딩테스트는 4문제 구성이며, 이 중 알고리즘 3문제 + SQL 1문제로 구성됐다는 후기 확인
- **알고리즘 유형**: 구현, 완전탐색, DP가 가장 자주 언급됨. 그 외 그래프 탐색(BFS/DFS), 투 포인터, 슬라이딩 윈도우, Union-Find 등도 출제 유형으로 언급됨
- **채용 철학**: 순수 알고리즘 난이도보다 실무 문제 해결 역량을 보려는 경향 — 코딩테스트는 1차 필터링 용도이고, 이후 단계에서 실제 역량을 더 깊게 본다는 후기가 다수
- **시간복잡도**: 효율성(시간 제한)을 명시적으로 강조하는 후기 다수 — 단순 정답이 아니라 시간복잡도까지 고려한 풀이를 요구하는 경향
