# SK하이닉스 — 코딩테스트 경향 기록

## 조사일자
2026-07-28 (최초 기록)

## 1단계 결과: 기출 여부
"SK하이닉스 코딩테스트 기출문제", "SK하이닉스 코딩테스트 후기" 검색 결과, 프로그래머스 환경을 채용 코딩테스트 플랫폼으로 사용한다는 정황은 다수 확인되었으나, 프로그래머스 "기업 기출문제" 코너나 SWEA, 공식 기술 블로그에 SK하이닉스 명의로 공개된 특정 문제명·문제 링크는 찾지 못함. 확인된 정보는 대부분 지원자 개인 후기(2018~2022년 공채 및 몰입캠프 후기 등) 수준 → **기출 불충분으로 판단, 2단계(경향 수집) 및 3단계(자체 제작)로 진행**.

## 2단계: 경향 요약
- **응시 환경 및 언어**: 프로그래머스 환경에서 진행되며, 대부분 C/C++만 허용(일부 IT 직무는 Python 허용). 정답을 반환하는 함수를 작성하는 방식이고 함수 시그니처(파라미터) 변경 불가, 여러 값을 반환할 때는 벡터 등에 담아 반환하는 관행이 후기에서 다수 언급됨.
- **문제 수·제한시간**: 시기별로 3~4문제, 제한시간은 90분 내외로 언급(2018년 후기 기준 3문제/90분). 최근 후기에서는 4문제를 모두 풀어도 불합격한 사례, 3문제만 풀고도 합격한 사례가 함께 언급되어 정답 개수만이 아니라 코드 품질(주석·스타일)도 채점 요소로 반영되는 것으로 보임.
- **알고리즘 유형·난이도**: "완전탐색 위주", "구현 문제가 많고 난이도는 쉬운 편"이라는 후기가 다수. 특정 고급 알고리즘보다는 기본적인 탐색·구현 역량을 확인하는 문제 스타일로 판단됨.
- **평가 철학**: 코딩테스트 결과를 이후 면접에서 리뷰하는 형태로 활용(문제를 어떻게 풀었는지 설명하는 방식)한다는 후기가 있어, 단순 정답 여부보다 풀이 과정과 코드 품질을 함께 보는 경향이 있음.
