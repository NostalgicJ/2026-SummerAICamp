# 배달의민족 — 코딩테스트 경향 기록

## 조사일자
2026-07-28 (최초 기록)

## 1단계 결과: 기출 여부
확정 불가. 프로그래머스 "기업 기출문제" 코너, SWEA, 공식 기술 블로그(우아한형제들 기술 블로그) 어디에서도 배달의민족(우아한형제들) 명의로 공개된 코딩테스트 문제를 찾지 못했습니다. 검색된 자료는 대부분 지원자의 개인 후기(velog, 개인 블로그)이며, 여러 후기에서 우아한형제들은 프로그래머스가 아니라 **Codility** 플랫폼을 코딩테스트 도구로 사용한다고 언급됩니다. Codility는 문제 풀(문항 자체)을 외부에 공개하지 않는 구조라 특정 문제명 + 신뢰 가능한 링크로 기출을 특정할 수 없었습니다. (백준에만 존재하는 자료는 애초에 소스에서 제외했습니다.) 따라서 2~4단계로 진행했습니다.

## 2단계: 경향 요약
여러 지원 후기를 종합한 정성적 요약이며, 원문 인용 없이 재구성한 내용입니다.
- **플랫폼**: 프로그래머스가 아닌 Codility 사용 사례가 다수 보고됨. 문제가 영어로 출제되고 테스트케이스가 노출되지 않는다는 후기가 있음.
- **시험 구성**: "3시간 동안 4문제" 구성을 언급한 후기가 있었고, 우아한테크캠프/우아한테크코스 계열 코딩테스트는 체감 난이도가 프로그래머스 레벨2~레벨3 수준(레벨2 문제 3개 + 레벨3 문제 1개 구성 등)이라는 후기가 확인됨.
- **유형 성향**: 알고리즘 자체의 난이도보다 "정확한 구현", "반례(엣지케이스) 찾기", "코드 디버깅형 문항"을 중시한다는 언급이 반복적으로 나타남. 시간복잡도까지 고려한 효율성 평가도 함께 이루어진다는 후기가 있음.
- **난이도 체감**: "중하 ~ 중" 수준으로 보고한 후기가 많고, 알고리즘 창의성보다 꼼꼼함/정확성을 테스트하는 경향으로 요약됨.
