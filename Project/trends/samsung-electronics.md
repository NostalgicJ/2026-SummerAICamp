# 삼성전자 — 코딩테스트 경향 기록

## 조사일자
2026-07-28 (최초 기록)

## 1단계 결과: 기출 여부
삼성전자는 자체 운영하는 SWEA(SW Expert Academy, swexpertacademy.com)에서 SW 역량테스트와 같은 형식의 연습 문제 및 모의검정 해설을 제공하고 있으나, 검색된 자료 어디에도 "이 문제가 실제 과거 SW 역량테스트 본 시험에 그대로 출제되었다"고 특정 문제명 + 신뢰 가능한 링크로 확정할 수 있는 자료는 없었음. SWEA 자체 안내에는 강의·연습문제·기출문제 등 아카데미 콘텐츠를 사전 동의 없이 복제·배포하지 말라는 안내만 확인됨(저작권 보호 대상이라는 정황은 있으나 "실제 기출"이라는 확정 근거는 아님). 프로그래머스에서도 삼성전자 명의의 "기업 기출문제" 코너는 확인되지 않음. 백준에는 "삼성 SW 역량 테스트 기출 문제" 문제집이 존재하지만, 이 프로젝트 정책상 백준은 소스로 인정하지 않음. 확인 가능한 정보는 대부분 응시자 후기(velog 등)와 사설 교육업체(코드트리) 블로그의 해설/전략 콘텐츠 수준에 머무름 → **기출 불충분으로 판단, 2단계(경향 수집 후 자체 제작)로 진행**.

## 2단계: 경향 요약
- **시험 구성**: A형은 보통 2문제(2~3시간 배정, 문제별 소요시간이 독립적으로 기록됨)가 출제되고, B형은 A형 합격자만 응시할 수 있으며 4시간에 1문제가 주어짐(후기마다 정확한 시간 배정은 다소 편차 있음)
- **응시 언어 제한**: A형은 Python 응시가 가능하지만, B형부터는 Python 응시가 불가능하고 C, C++, Java로만 응시 가능하다는 후기가 다수 확인됨 — 회사별 언어 제한이 뚜렷한 편
- **문제 스타일**: A형은 2차원 배열을 활용한 구현·시뮬레이션 문제 비중이 높고(시간/메모리 초과는 잘 발생하지 않음), B형은 배열·문자열 처리·그래프·동적 프로그래밍 등 알고리즘 지식과 효율적인 구현을 함께 요구하며 시간복잡도 개선이 채점 포인트가 됨
- **난이도**: 등급이 IM(초급) < A < B < C(고급) 순으로 나뉘며, 응시 후기들은 대체로 "난이도는 매번 다르지만 시간 관리가 합격을 좌우한다"는 공통된 평가를 보임
- **자료구조/알고리즘 유형**: 스택, 큐, 트리, 힙, 해시 등 기본 자료구조와 정렬, 브루트포스(완전탐색), BFS/DFS, 다이나믹 프로그래밍, 최단경로(다익스트라류) 등이 자주 언급됨. 지문이 길고 규칙이 세밀하게 명시된 시뮬레이션형 구현 문제가 특징적으로 자주 언급됨
