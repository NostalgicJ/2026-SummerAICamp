# AlGoPing 소개 페이지 — Acid Yellow 디자인 언어 버전

`Project/artifacts/algoping-showcase.html`(기존 인디고·라벤더 톤)과 별개로, claude.ai/design의
"애시드 옐로우 웹 디자인 가이드" 프로젝트(`d2dbe2b4-19c3-4775-8300-f26158bf64fc`)에 정의된 디자인
언어를 전체 적용해서 만든 버전이다.

- **게시된 페이지**: https://claude.ai/code/artifact/a4de3732-21bf-4df0-891b-70dd80e6493b (비공개, 조직 공유는 Share에서 별도 설정 필요)
- **소스**: `algoping-showcase.html` (이 폴더)

## 기존 버전과 다른 점

| 항목 | 기존 버전 | 이 버전 |
|---|---|---|
| 색 | 인디고(#6367ff) + 라벤더 톤 배경 | 베이지 캔버스(#F6F4EC) + 잉크(#1B1A17) + 라임(#C6F24E, 면) + 시그널 블루(#1F5EF7, 글자) |
| 타이포 | 시스템 라운드체 + Pretendard | Pretendard 900 대문자 초대형 헤드라인, n.001~n.006 섹션 넘버링 |
| 모서리·그림자 | 둥근 모서리 + 소프트 섀도우 | radius 0(버튼만 pill), 그림자 없이 1px 헤어라인으로만 구분 |
| 흐름도 | 아이콘 원형 배지 + 그라데이션 연결선 | 01~06 번호가 붙은 헤어라인 리스트 (아이콘 최소화) |
| 아코디언 | 화살표(▾/▴) 회전 | +/− 사인 전환 |
| 히어로 | 알림·폰 목업 콜라주 포함 | "타입 자체가 이미지" 원칙에 따라 목업 제거, 실제 목업은 n.003 실제 동작 화면 섹션에서만 |
| 다크 모드 | 자체 팔레트 | 디자인 가이드가 문서화한 공식대로 캔버스/잉크 반전 + 시그널 블루를 `#6E9BFF`로 밝게 |

Pretendard 폰트 서브셋 임베드, 인터랙션(흐름 클릭·아코디언·Q&A 토글·시뮬레이터 탭/건너뛰기/풀었음 체크·스크롤 리빌)은
기존 버전과 동일하게 전부 유지된다.
