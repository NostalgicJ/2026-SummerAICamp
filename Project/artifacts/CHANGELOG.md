# AlGoPing 소개 Artifacts 페이지 — 변경 기록

`algoping-showcase.html`은 알고핑(AlGoPing) 프로젝트를 소개하는 Artifacts 페이지다.
Claude Code와의 대화로 만들고 다듬었으며, 아래는 그 과정에서 실제로 주고받은 피드백과 수정 순서를
그대로 남긴 기록이다. 게시된 페이지 자체는 claude.ai Artifacts에 있고(비공개, Share에서 조직 공유 설정 필요),
이 파일은 그 소스와 변경 이력의 저장소 내 사본이다.

## 초안

- PRD.md / TODO.md를 근거로 히어로, "왜 만들었나", 시스템 동작 흐름, 실제 동작 화면 시뮬레이터(4탭),
  개발 시행착오, 그룹 Q&A, 진행 상황(Phase 트래커) 섹션으로 구성한 첫 버전 작성.
- 로컬에서 실행한 실제 앱 화면을 스크린샷으로 확인한 뒤, 그 내용을 그대로 재현한 인터랙티브 시뮬레이터로 구현
  (실제 스크린샷 이미지 파일 대신 실제 색상 변수·문구를 그대로 옮긴 HTML/CSS 재현 방식 채택).

## 피드백 반영 순서

1. **헤드라인 줄바꿈 깨짐** — "기업마다 다른 출제 경향, 무작위로 풀지 않기로 했다."에서 "했다"가
   "했"/"다."로 쪼개져 보임.
   → 한글은 기본적으로 음절 단위 어디서나 줄바꿈되는 것이 원인. `word-break: keep-all` 적용,
   히어로 텍스트 컬럼 폭(그리드 비율)과 폰트 크기 조정.

2. **본문 문단 배치가 어색함 + 전체적으로 글자가 작고 레이아웃이 빡빡함** — Intent/System Flow 등
   섹션 설명 문단(`.sub`)의 줄바꿈이 들쭉날쭉해 보임.
   → `max-width`를 `ch` 단위(한글 폭 계산이 부정확)에서 고정 px로 변경, `text-wrap: pretty` 추가.
   "동작 흐름" 이후 전 섹션(흐름도 노드, 시뮬레이터, 시행착오 타임라인, Q&A, phase 트래커)의
   폰트 크기·여백을 한 단계씩 확대.

3. **흐름도 노드 하나만 어색함** — "🔔 기기 알림 → 클릭" 노드 하나만 제목 안에 화살표가 들어 있어
   전체 흐름을 잇는 화살표와 헷갈림.
   → "기기에 알림 도착" / "알림 클릭 → 앱 진입" 두 단계로 분리.

4. **시뮬레이터 탭 순서가 실제 앱과 다름** — 실제 앱은 오늘의 문제 → 풀이 기록 → 알고리즘 → 설정 순.
   → 탭 버튼과 화면 패널 마크업 순서를 실제 앱과 동일하게 정렬.

5. **동작 흐름 다이어그램이 예쁘지 않음** — 박스 여러 개를 "→" 텍스트로 잇는 가로 배치가 노드 6개로
   늘어난 뒤 줄바꿈이 지저분해짐.
   → 아이콘 원형 배지 + 연결선으로 이어지는 세로형 파이프라인으로 전면 재설계
   (지하철 노선도 스타일, 화면 폭에 관계없이 항상 동일한 레이아웃).

6. **storage.js 안내 문구가 토막나서 보임** — "storage.js / 판정·계산 단계는 모두 / Postgres(Neon) /
   또는 / 로컬 파일 폴백 / 과 함께 동작한다"처럼 문장이 쪼개짐.
   → 원인은 `display:flex`인 콜아웃 박스 안에 텍스트와 pill 배지가 섞여 있어 flex가 문장 조각을
   각각 별도 줄바꿈 단위로 취급한 것. `display:flex` 제거, 일반 문단(`<p>`)으로 재구성.

7. **storage.js 안내 문구 위치가 어정쩡함 + 전체적으로 너무 정적임**
   → `margin-left: 78px` 들여쓰기를 없애고 아이콘(🗄️) + 문장을 가로 배치한 카드로 재배치,
   나머지 콘텐츠와 같은 왼쪽 라인에 정렬.
   → 인터랙티브 요소 대거 추가: 흐름도 각 단계 클릭 시 하이라이트, 시행착오 타임라인 아코디언(클릭해
   펼치기), Q&A 질문 탭하면 답변 펼쳐짐, 시뮬레이터 "건너뛰기"가 실제 problems.json의 다른 문제로
   전환, "풀었음 체크" 버튼 상태 토글, Intent 카드 호버 효과, 스크롤 리빌 애니메이션
   (`prefers-reduced-motion` 존중).

8. **제목(워드마크)을 더 크고 눈에 띄게** — "AlGoPing" 표기로 통일, 로고·글자 크기 확대,
   "Algorithm + Go + Ping의 합성어" 설명 문구 추가.

9. **태그라인 문구가 별로임** — 사전적 설명("Algorithm + Go + Ping의 합성어") 대신
   제품 동작과 이어지는 문장으로 교체 → "Algorithm이 Go하면, Ping이 온다."

10. **히어로 비주얼이 작고 밋밋함 + Q&A 정렬이 어색함**
    - 히어로: 폰 카드 확대(320→380px), 은은하게 맥동하는 글로우, "어제" 알림을 흐리게 겹쳐 쌓은
      스택 연출, 폰 카드 상시 float 애니메이션, "🔥 3일 연속 도착" 스트릭 배지 추가.
    - Q&A: 질문(🙋)은 왼쪽, 답변(🔔)은 오른쪽(아바타도 반전)으로 정렬해 실제 대화하는 느낌으로 재구성.

11. **통계 태그 추가 요청** — 기존 4개(38문제·9개 기업군 / 26종 알고리즘 사전 / 로그인 없음 /
    라이트·다크 완전 대응)에 PRD/TODO에서 검증된 사실 4개 추가:
    출제 순서 3가지, PWA·홈 화면 설치, GitHub PR로 계속 확장, 인프라 완전 무료.

12. **태그가 늘어나며 히어로 비주얼이 위로 떠 보임** — 왼쪽 컬럼이 3줄로 길어지며 오른쪽 알림 스택이
    상대적으로 위쪽에 붕 뜬 것처럼 보임.
    → 비주얼 박스 높이(540→500px) 축소, 알림 카드 위치를 아래로 조정해 왼쪽 컬럼과 대칭적으로
    중앙 정렬되도록 재조정.
